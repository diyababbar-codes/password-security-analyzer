Password Security Analyzer

About the Project

Password Security Analyzer is a C language-based project that checks password strength.

Features

- Checks password length.
- Detects uppercase and lowercase letters.
- Detects numbers and special characters.
- Calculates a security score.
- Classifies passwords as Weak, Moderate or Strong.

Technology Used

- C Programming Language
- Code::Blocks

Purpose

To help users understand password strength and encourage better password security.
